# Screenshots — Dead Reckoning

Gallery images for the Nexus listing, in upload order. Captions and the banner/thumbnail plan
live in [../NEXUS.md](../NEXUS.md#screenshots).

These are the real in-game captures the user provided (from Downloads, 2026-08-21), renamed and
ordered — nothing here is generated. `01-change-flame-colour.png` (2.80:1) is the widest full
scene and the best banner candidate; none of the shots is a clean 16:9, so if the listing
thumbnail looks stretched, compose a 16:9 one from it (tiles use `object-fit: fill`).

Two video clips (follow-your-soul-blob, quest-tracking) are set aside for a later pass — Nexus's
image gallery does not take video.
